# My Project

Final Project Reflection

This project started from a curiosity of how 3D terrain generation worked, especially since it is a core technique used in games such as Minecraft and Terraria. I wanted to understand how to generate natural looking landscapes. This skill felt relevant to my 3D game design works and could perhaps aid in my future projects in open world games. 

My original plan was to integrate an Arduino touch sensor which will collect a set of data from inputs from the user. However, this method proved to be ineffective in allowing users to interact and customize the terrain much. There was also significant lag in having a constant serial communication and noise recalculation. 

I shifted to implementing more interactivity through HTML sliders and also fixing the lag. This change made the program much faster and allowed more creative opportunities. I wanted to allow users to adjust the noise level, terrain height and colours. I also shifted towards making it look like a planet because it looked cooler. There were some technical issues such as spherical distortion as map plastered on the sphere made it look stretched and warped near the poles, breaking the even natural formations.

Overall this project has been very fruitful and I have achieved the objectives of starting this project. With more experience I would like to apply better and custom textures.
